# Satisfactory Manager

Blueprint-Erweiterung für das Pterodactyl Panel: Status, Savegames, Server-Einstellungen und Extras für Satisfactory Dedicated Server, direkt im Panel.

> 🚧 In Entwicklung. Den Fahrplan findest du in [PLAN.md](PLAN.md).

## Entwicklung

```bash
./scripts/dev-sync.sh          # extension/ ins Panel kopieren und bauen
./scripts/dev-sync.sh --watch  # bei jeder Änderung automatisch neu bauen
./scripts/package.sh           # dist/sfmanager.blueprint erzeugen
```

Voraussetzungen: Pterodactyl mit [Blueprint](https://blueprint.zip) und eingeschaltetem Developer-Modus.
