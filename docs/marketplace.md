Run Satisfactory dedicated servers with ease: status, savegames, backups, settings, restarts and updates in your panel.

## Tags
satisfactory, game server, savegames, backups, automation, monitoring

## Description (EN)

Satisfactory Manager brings everything you need to run **Satisfactory dedicated servers** into the Pterodactyl panel – no game client, no SSH, no fiddling with config files.

**Highlights**
- 🟢 **Live status** – players, tech tier, Space Elevator phase, tick rate and play time, plus history charts and a badge in the server list
- 🪄 **Setup without the game** – claim a fresh server, set passwords and start a new game right in the panel
- 💾 **Savegame manager** – download, upload (up to 100 MB), load and delete saves, choose the session loaded on start
- 🛟 **Backups** – manual or scheduled, automatically before restarts, updates and loading; one-click restore
- ⏰ **Scheduled restarts** that save first – optionally only when nobody is online
- 🩺 **Crash watchdog** – restarts servers that run but stopped responding
- 🔄 **Update centre** – see when a new build is out, switch between public and experimental, back up & update in one click
- ⚙️ **Settings** – server options, advanced game settings, server name and passwords with friendly labels
- 🖥️ **Console** with command history
- 🛡️ **Admin page** – all Satisfactory servers at a glance, every feature can be switched off

**Safe by design:** every action respects Pterodactyl permissions (subusers included) and is written to the activity log. The Satisfactory admin password is never stored – only an encrypted token. No telemetry. English and German included.

**Requirements:** Satisfactory 1.0+ (dedicated server HTTPS API), the Satisfactory egg from pterodactyl/game-eggs (or compatible), game port and reliable port as allocations, Laravel scheduler (cron).

*Unofficial community project, not affiliated with Coffee Stain Studios. Satisfactory is a trademark of Coffee Stain Studios AB.*

## Beschreibung (DE)

Satisfactory Manager bringt alles, was man zum Betrieb von **Satisfactory Dedicated Servern** braucht, ins Pterodactyl Panel: ohne Spiel-Client, ohne SSH, ohne Konfigurationsdateien.

**Highlights**
- 🟢 **Live-Status**: Spieler, Tech-Tier, Weltraumaufzug-Phase, Tickrate und Spielzeit, dazu Verlaufsdiagramme und eine Anzeige in der Serverliste
- 🪄 **Einrichtung ohne Spiel**: frischen Server claimen, Passwörter setzen und direkt ein neues Spiel starten
- 💾 **Savegame-Manager**: Saves herunterladen, hochladen (bis 100 MB), laden und löschen, Session für den Serverstart festlegen
- 🛟 **Backups**: manuell oder geplant, automatisch vor Neustarts, Updates und dem Laden; Wiederherstellen per Klick
- ⏰ **Geplante Neustarts**, die vorher speichern, optional nur, wenn niemand online ist
- 🩺 **Absturz-Wächter**: startet Server neu, die laufen, aber nicht mehr antworten
- 🔄 **Update-Center**: zeigt neue Builds, wechselt zwischen public und experimental, Backup & Update mit einem Klick
- ⚙️ **Einstellungen**: Server-Optionen, erweiterte Spieleinstellungen, Servername und Passwörter mit verständlichen Namen
- 🖥️ **Konsole** mit Befehlsverlauf
- 🛡️ **Admin-Seite**: alle Satisfactory-Server auf einen Blick, jede Funktion abschaltbar

**Sicher gebaut:** Jede Aktion beachtet die Pterodactyl-Rechte (auch Unternutzer) und landet im Aktivitätslog. Das Satisfactory-Admin-Passwort wird nie gespeichert, nur ein verschlüsselter Token. Keine Telemetrie. Deutsch und Englisch enthalten.

*Inoffizielles Community-Projekt, keine Verbindung zu Coffee Stain Studios. Satisfactory ist eine Marke von Coffee Stain Studios AB.*
